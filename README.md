# Kriyvo AI

Website for Kriyvo AI — freelance web development, AI chatbots, voice agents and n8n automation, based in Delhi NCR.

Built with TanStack Start, React 19, Tailwind CSS 4 and Vite.

## Development

Requires Node.js 22+.

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build (Nitro auto-detects the deploy target, e.g. Vercel or Node)
- `npm run preview` — preview the production build
- `npm test` — run tests
- `npm run lint` — lint

## Content

- Home page: `src/routes/index.tsx`
- Projects, case studies, contact details: `src/lib/kriyo-data.ts`
- Services: `src/lib/services-data.ts`, `src/lib/service-details.ts`
- Journal articles: `src/lib/blog-data.ts`
